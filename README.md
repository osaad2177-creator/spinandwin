# Industrial Tower — Spin & Win

Simple fullscreen touchscreen kiosk game using the supplied client reference images.

Flow: Start → Spin → Win → Collect Gift → New Player.

The five supplied prize-design images are used directly as the visual shown for each matching prize on the winning screen.

- reference-1.jpeg → 2 cartons
- reference-2.jpeg → 3 cartons
- reference-3.jpeg → 6 cartons
- reference-4.jpeg → 10 cartons
- reference-5.jpeg → cash-back
- reference-6.jpeg / reference-7.jpeg → wheel references
- reference-8.jpeg → prize-list reference

Open `index.html` directly or deploy the folder to GitHub/Vercel.
