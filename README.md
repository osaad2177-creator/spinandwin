# Industrial Tower — Spin & Win

Simple fullscreen touchscreen kiosk game.

## Run
Open `index.html` directly in a browser, or deploy the folder to GitHub/Vercel.

## Game
Start → Spin → Win → Collect Gift → New Player.

## Prizes
- عدد 2 كرتونة
- عدد 3 كرتونة
- عدد 6 كرتونة
- عدد 10 كرتونة
- كاش باك 10 جنيه

The winning prize is selected in JavaScript before the wheel animation and the wheel is rotated to that segment.

## Assets
The supplied reference images are stored in `assets/` for use/reference when refining the visual branding.
